## Findings

1. **minor** (not new: since 0.0.4, in lines 5a32b9f moved into `preflight`): the user's plugin settings file is looked for in another folder than goose's when `HOME` is unset or empty. Files: src/plugin.rs:207-210, src/util.rs:8-12; `crates/goose/src/plugins/discovery.rs:226-241`.
   - **What happens.** With no `GOOSE_PATH_ROOT`, `preflight` reads `<home>/.config/goose/settings.json`, where `home_dir()` is `$HOME`, else `/`. An empty `HOME` gives an empty path, so the file is read relative to goose-triggers' own folder. goose uses `dirs::home_dir()`. Its dirs-sys 0.5.0 treats an empty `HOME` as unset and then takes the home folder from the system's user database. Case: `goose-triggers run` started with no `HOME` (under `env -i`, or by a service manager that does not set it), as a user whose `~/.config/goose/settings.json` lists `goose-triggers` in `disabledPlugins`. The start check reads `/.config/goose/settings.json` and passes. goose skips the plugin. The runner's guard (src/runner.rs:652-664) stops goose only after the first unheld call has run, then fails the run. `goose_config_dir()` (src/plugin.rs:98-103), through `config_home()`, uses the same fallback for the config files that hold `plugins:`.
   - **How likely.** Low. It needs both an environment with no usable `HOME` and a settings file that turns the plugin off.
   - **Fix.** In `home_dir()`, treat an empty `HOME` as unset, and fall back to the user database (`libc::getpwuid_r`), as goose does. Or refuse to start with no usable `HOME`, saying why.

2. **nit**: the older plugin test still reads the developer's own goose settings. File: src/plugin.rs:274-297. It calls `preflight`, which reads the real `PLUGINS`, goose's config files and `~/.config/goose/settings.json`. On a machine whose user settings list `goose-triggers` in `disabledPlugins`, line 283 fails, though the code is right. The test also leaves its folder in the temporary folder. Fix: call `preflight_with(&dir, None, &[], &<a user folder that does not exist>)`, and remove the folder at the end.
