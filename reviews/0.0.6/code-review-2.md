## Findings

1. **nit**: `tests/keep.rs` needs `/bin/false`. Files: tests/keep.rs:23, 38-42; src/selftest.rs:982-991 (`resolve_goose`).
   - **What happens.** The test passes `--goose /bin/false`. `resolve_goose` resolves a path of more than one part, and refuses one that does not exist before any folder is made. On a system with no `/bin/false`, the `--keep` case finds no folder, and `assert_eq!(left.len(), 1)` fails. The test fails though the code is right.
   - **The case.** `cargo test` on a Linux system whose `/bin` holds only `sh` (NixOS, some small container images).
   - **How likely.** Rare: CI and most systems have `/bin/false`.
   - **Fix.** Write a small script that exits 1 into the test's own folder, make it executable, and pass its path.

2. **nit**: the new upgrade paragraph comes between the two ways to install. Files: README.md:47, 49-53.
   - **What happens.** The paragraph follows the release's Install block, so "Or from source, ..." now follows a paragraph about upgrades and reads as an alternative to it. The paragraph holds for both ways to install: `cargo install` over an older release replaces the binary the same way.
   - **How likely.** Only a reading matter.
   - **Fix.** Move the paragraph after the `cargo install` block.
